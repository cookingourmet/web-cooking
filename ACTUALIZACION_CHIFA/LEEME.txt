INSTALACIÓN
Desde Git Bash:

bash INSTALAR.sh /d/web/web-cooking

El instalador:
- acepta el proyecto original o la actualización anterior;
- guarda un respaldo antes de copiar;
- aplica todos los archivos de esta versión;
- ejecuta npm run build;
- deja el proyecto compilado y listo para publicar.
